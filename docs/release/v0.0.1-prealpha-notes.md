# v0.0.1-prealpha

This is the first public pre-alpha foundation release of GnuCash Web Companion.

## Status

Pre-alpha. Not production-ready. Not audited.

## Safety warning

Use only with a disposable/test copy of a GnuCash SQL book first. Do not expose directly to the public internet. Keep backups. Do not enable write mode against your only copy.

## What is included

- SvelteKit frontend
- FastAPI backend
- Docker Compose + Caddy scaffold
- local admin authentication foundation
- app metadata DB
- default book registry
- read-only GnuCash service layer through piecash
- account browsing
- transaction browsing
- basic dashboard reports
- mobile/theme/PWA foundation

## What is not included

- production hardening
- security audit
- write operations enabled by default
- collaborative editing
- bank integrations
- CSV/OFX import
- guaranteed multi-currency report conversion

## Controlled writes

Experimental controlled-write code may exist in the repository, but it is disabled by default:

```text
GNUCASH_WRITES_ENABLED=false
```

Controlled writes are post-MVP and require more safety work before real use.

## Known limitations

- Real GnuCash fixture validation still needed.
- No production deployment guidance yet.
- Multi-currency reporting is conservative.
- Write-mode lock is not production-ready.
