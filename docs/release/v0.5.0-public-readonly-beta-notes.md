## Release posture

This is a conservative public read-only beta for careful external testers.

Boundaries:

- Not production-ready.
- Not stable.
- Not security-audited.
- Not safe to expose directly to the public internet.

## Included

- Read-only web companion for GnuCash SQL books.
- Public read-only install guide.
- Security/privacy posture and feedback packet.
- Backend/frontend/Docker/public-status checks passed before publication.

## Not included

- No public write beta.
- No production/security audit claim.
- Safety claim for original, private, real working, or only-copy books.
- Hosted service/SaaS support.

## Required defaults

`GNUCASH_WRITES_ENABLED=false` remains the default in `.env.example` and Docker Compose.
Controlled writes remain experimental and disabled by default.
