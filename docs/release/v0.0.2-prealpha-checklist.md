# v0.0.2-prealpha Release Candidate Checklist

> Status: published in Phase 42 after the release-gate audit passed and checks were green. This is still a pre-alpha release, not production-ready.

## Scope

Second pre-alpha candidate for review and experimentation after `v0.0.1-prealpha`.

This candidate remains conservative:

- pre-alpha only;
- not production-ready;
- not security-audited;
- read-only by default;
- GnuCash Desktop remains the authoritative editor;
- controlled-write code is experimental post-MVP work and disabled by default with `GNUCASH_WRITES_ENABLED=false`.

## Included since v0.0.1-prealpha

- Synthetic disposable GnuCash SQLite fixtures.
- Read-only integration validation against fixture books.
- README screenshots using synthetic data only.
- Multi-currency limitation tests and documentation.
- Multi-book UI foundation and book-aware frontend routes.
- Read-only CSV export for transactions.
- Transaction amount range filters for browsing and CSV export.
- GnuCash compatibility matrix for committed synthetic fixtures.
- Personal read-only dogfood guide.
- Automated read-only API smoke script for local Docker deployments.
- Public documentation/status synchronization through Phase 40.

## Safety hardening since v0.0.1-prealpha

- File-based `fcntl.flock()` write lock service for experimental write mode.
- Disposable-book controlled-write integration tests.
- Backup restore smoke tests.
- Disabled-write regression coverage for validate/create/patch write endpoints.
- Persistent read-only-by-default UI status banner.
- Experimental write-mode warning UI and required acknowledgement before final create submission.
- Controlled-writes documentation cleanup confirming write mode remains post-MVP and disabled by default.

## Explicitly not included

- Production readiness.
- Audited security guarantee.
- Default-enabled writes.
- Safe write-mode guarantee for real books.
- New write capabilities beyond the already-gated experimental post-MVP code.
- Collaborative accounting or family-wallet baseline.
- Banking integrations.
- CSV/OFX import.
- Broad GnuCash version compatibility guarantee.
- PostgreSQL/MySQL/MariaDB or XML book compatibility validation.

## Required pre-release gate

Before publishing `v0.0.2-prealpha`, Phase 41 must complete a release-gate audit with a release verdict of either:

- Ready for pre-alpha release; or
- Ready after listed blockers, with all blockers fixed and verified.

If blockers remain, do not publish the tag or GitHub release.

## Automated checks

Run from repository root unless noted:

```bash
cd apps/api && pytest -q
cd apps/web && npm run check && npm run test:auth-routes && npm run build
JWT_SECRET=dummy-validation-secret APP_ADMIN_PASSWORD=dummy docker compose config --quiet
git diff --check
```

## Optional local deployment smoke

Against a local Docker/Caddy deployment using a copied/disposable book only:

```bash
SMOKE_API_BASE_URL=http://localhost:8080/api \
SMOKE_ADMIN_USERNAME=admin \
SMOKE_ADMIN_PASSWORD='<local-admin-password>' \
python3 scripts/smoke/read-only-api-smoke.py
```

The smoke script checks health, login, `/auth/me`, book discovery, book metadata, accounts, transactions, reports summary, and disabled-write 403 responses.

## Manual smoke checklist

Use `scripts/smoke/read-only-smoke-check.md` and `docs/dogfood/personal-readonly-dogfood.md`.

Minimum manual confirmations:

- use only a copied/disposable GnuCash SQL book under `data/books/`;
- keep `GNUCASH_WRITES_ENABLED=false`;
- login works;
- dashboard loads;
- accounts tree and account detail load;
- transactions list and transaction detail load;
- CSV export downloads expected synthetic/copied-book data;
- write entry points are hidden while writes are disabled;
- no real screenshots, exports, `.env`, app DB, backups, secrets, keys, or tokens are committed.
