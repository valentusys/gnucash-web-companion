## 2. Candidate evidence from Phases 183–190

Meaningful work after `v0.2.1-writealpha`:

- Safe lock inspection and operator guidance for active/stale/unreadable lock states.
- One explicit local-only synthetic/disposable PATCH dogfood pass with read-back, backup, audit, safe missing-transaction behavior, default-disabled reset, and teardown.
- One explicit local-only synthetic/disposable DELETE dogfood pass with restore proof in Phase 185.
- Read-only audit-summary endpoint/UI for write-alpha evidence with path/payload/memo/amount redaction.
- Multi-book read-only access regression and selected-book recovery hardening.
- Reporting correctness edge cases for mixed currency, unknown base currency, zero fallback, signed balances, Decimal/string amounts, and drilldown URL parity.
- Fresh-clone install smokes for `v0.1.7-readonly`, `v0.2.1-writealpha`, and `main`, all under default disabled writes.
- Combined release-candidate default read-only API/browser dogfood plus separate explicit local-only create/PATCH/DELETE write-alpha route-family evidence.

All write evidence is synthetic/disposable evidence. No real/private-book write safety is claimed.

## 7. Known limitations and open risks

- Write-alpha is intentionally test-gated and disabled by default.
- Real/private-book write safety is not established.
- Compatibility evidence remains intentionally narrow; future real Desktop-generated synthetic SQLite fixture coverage is still useful.
- CSV export remains synchronous and capped at 10,000 rows.
- Russian localization remains incomplete and English remains canonical.
- The project remains pre-alpha, not production-ready, and not security-audited.
- GitHub Actions currently emit a Node.js 20 action deprecation warning for `actions/checkout@v4`; this is non-blocking for this release but should be tracked in a later maintenance phase.
