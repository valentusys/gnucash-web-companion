# v0.2.9-writealpha no-release verdict

Status: NO-RELEASE / NO_RELEASE — current Phase 298 support document for the Phase 297 decision.

## Current decision

Do not publish `v0.2.9-writealpha`.

The current public experimental write-alpha pre-release remains `v0.2.8-writealpha`. No tag, GitHub release, package, image, stable release, or production deployment is authorized or created.

## Why no release

Phase 294/295 added meaningful owner copied-book evidence, but it is narrow evidence only:

- one copied/restorable working book outside git;
- exactly one CREATE;
- exactly one metadata/memo-only PATCH on the same write-alpha-created transaction;
- required backup/read-back/audit/lock/compatibility/restore/reset/redaction checks recorded as passing;
- DELETE not run.

This is not a user-facing runtime capability, not a broad safety correction, and not a reason to market a new public write-alpha release. Publishing `v0.2.9-writealpha` now could make the copied-book CREATE-to-PATCH evidence look broader than it is.

## Safety posture preserved

- `GNUCASH_WRITES_ENABLED=false` remains the default.
- Explicit write-alpha remains `APP_ENV=test` gated.
- PATCH remains metadata/memo-only.
- Owner DELETE remains blocked/not run.
- Original/private/only-copy books remain forbidden and unsupported for write-alpha.
- No production readiness, security audit, public-internet safety, broad GnuCash compatibility, DELETE readiness, or general private-book write-safety claim is made.
