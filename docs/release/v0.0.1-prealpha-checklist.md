# v0.0.1-prealpha Release Checklist

## Scope

Read-only-first pre-alpha foundation.

## Included

- login/logout
- default book registry
- read-only GnuCash adapter
- accounts browsing
- transactions browsing
- dashboard reports
- mobile/theme foundation
- Docker Compose scaffold
- CI scaffold

## Explicitly not included

- production readiness
- audited security
- write operations by default
- collaborative editing
- bank sync/import
- CSV/OFX import
- real multi-currency conversion guarantee

## Pre-release checks

Commands:

```bash
cd apps/api && pytest -q
cd apps/web && npm run check
cd apps/web && npm run test:auth-routes
cd apps/web && npm run build
JWT_SECRET=dummy-validation-secret APP_ADMIN_PASSWORD=dummy docker compose config --quiet
git diff --check
```

## Manual smoke test

- clone repo
- `cp .env.example .env`
- set real `JWT_SECRET`
- set local admin password/hash
- place disposable GnuCash SQL book under `data/books/`
- `docker compose up --build`
- login
- open dashboard
- open accounts
- open transactions
- verify writes are not visible/enabled

## Release commands

Only if all checks pass:

```bash
git tag -a v0.0.1-prealpha -m "v0.0.1-prealpha"
git push origin v0.0.1-prealpha
```
