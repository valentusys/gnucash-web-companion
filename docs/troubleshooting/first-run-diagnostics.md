# First-run diagnostics

Open `/diagnostics` before sharing setup reports. Safe fields include status labels, booleans, and generic next actions for JWT/admin bootstrap, default-book reachability, app DB reachability, CORS posture, and write-mode default.

Do not share books, app DBs, backups, exports, screenshots, `.env`, tokens, private paths, account names, descriptions, memos, or amounts. Public beta remains read-only; use GnuCash Desktop for edits.
