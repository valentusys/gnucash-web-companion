## Safety boundary

- `Settings.gnucash_writes_enabled: bool = False` remains the backend default.
- `apps/api/app/routers/transactions.py` calls `_ensure_writes_enabled(settings)` before resolving books/access and before constructing the write service for validate/create/patch routes.
- `apps/api/tests/test_transaction_writes.py::TestWritesDisabledByDefault` contains regression coverage proving disabled validate/create/patch routes return read-only 403 responses without calling `_write_service_for`.
- Frontend storage search found `localStorage` only for theme preference, not auth token storage.
- No evidence was found that Phase 36 enabled writes by default or broadened write scope.
