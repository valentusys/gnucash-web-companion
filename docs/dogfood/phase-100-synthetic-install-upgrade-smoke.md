## Tooling drift found and fixed

The PM brief expected `python3 scripts/smoke/read-only-api-smoke.py --help` to be a non-mutating help check. The existing script did not implement CLI help and tried to run the smoke immediately, failing when no admin password was provided.

Narrow fix in this phase:

- added `argparse` help/options for `--api-base-url`, `--username`, and `--password`;
- preserved existing environment-variable defaults;
- added smoke coverage for transaction detail and CSV export;
- made CSV export metadata header checking case-insensitive because Caddy/HTTP canonicalizes header casing.

Verification:

```bash
python3 scripts/smoke/read-only-api-smoke.py --help
python3 -m py_compile scripts/smoke/read-only-api-smoke.py
SMOKE_ADMIN_PASSWORD=dummy scripts/smoke/read-only-api-smoke.py
```

All passed after the fix.
