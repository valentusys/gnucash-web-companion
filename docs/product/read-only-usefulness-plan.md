# Read-only product usefulness plan

PM-selected final product improvement for Phases 611-620: improve practical read-only beta adoption rather than expanding write scope.

## Selected slice

Make the read-only beta easier to try, diagnose, and report safely:

- first-user checklist;
- safe feedback packet and issue-template wording;
- deployment diagnostics/privacy guide;
- tracked hygiene guard;
- final no-release decision rather than publishing a tag without user-visible runtime changes.

## Deferred product ideas

Create normal GitHub issues instead of another automatic phase train for:

1. In-app read-only diagnostics page polish.
2. Multi-book onboarding improvements.
3. Compatibility report upload/redaction workflow using only synthetic metadata.
4. Account/transaction search and saved filters.
5. Owner-writebeta state-machine implementation beyond current write-alpha prototype.

## Boundaries

- No public write beta.
- No real working-book mutation.
- No default write enablement.
- No production/stable/security-audited/public-internet-safe claim.
