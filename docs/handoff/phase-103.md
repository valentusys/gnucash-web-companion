## Implementation summary

Added date-range preset controls to the transactions filter UI:

- `This month`
- `Last month`
- `Year to date`
- `Clear dates`

The presets are normal accessible links generated by the transactions server load. They populate the existing `date_from` and `date_to` URL query parameters only, preserving the existing backend/API contract.

Filter behavior preserved:

- search query is preserved;
- selected account filter is preserved;
- min/max amount filters are preserved;
- pagination offset resets to `0` when a preset is applied;
- custom date inputs remain visible and usable;
- active filter summary continues to show applied date ranges;
- CSV export URL continues to preserve the same active filters as the read-only transaction list.

No backend API, write route, GnuCash service, money calculation, import/export format, or persistence/storage behavior was changed.
