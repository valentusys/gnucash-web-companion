Date: 2026-05-18
Role: Project Lead / PM

Source roadmap: `docs/audits/2026-05-18-analyst-10-phase-plan.md`, extended after Phase 103 because current `main` is already complete through Phase 103

## Decision

Plan Phase 104 as the next practical, non-publishing, read-only engineering phase: improve transaction search semantics from GitHub #11 by making the existing `query` filter match split memos in addition to transaction descriptions.

The analyst 10-phase plan has already been executed through Phase 103 on current `main`. The roadmap's original Phase 104 was a consolidation/status step, but Val explicitly requested no audit-only/docs-only work. The best next practical slice is therefore a narrow continuation of the Phase 103 / GitHub #11 transaction-search work: broaden the existing read-only query behavior to include split memos, which are already exposed on transaction detail and can be inspected safely through the existing read-only service layer.

## Goal

Extend the existing transaction `query` filter so users can find read-only transactions by text in:

- transaction description; and
- split memo fields.

The same query semantics must apply consistently to:

- backend transaction list;
- backend transaction count/pagination totals;
- backend CSV export;
- frontend transaction list/filter UI; and
- CSV export links generated by the web app.
