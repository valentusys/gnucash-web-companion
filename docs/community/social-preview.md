# Social Preview Setup

GitHub social preview images are configured in the repository web UI, not in git.

## Manual steps

1. Open repository settings:
   `https://github.com/valentusys/gnucash-web-companion/settings`
2. Go to **Social preview**.
3. Upload an image that uses only project branding or synthetic UI data.
4. Do not use real financial screenshots, real GnuCash books, account names, balances, or private deployment URLs.

## Recommended image copy

```text
gnucash-web-companion
Self-hosted read-only web companion for GnuCash books
Pre-alpha • test copies first
```

## Safety checklist

- [ ] No real financial data.
- [ ] No real customer/vendor names.
- [ ] No tokens, hostnames, private URLs, or credentials.
- [ ] No production-ready/security-audited claims.
- [ ] Read-only/pre-alpha positioning remains visible.
