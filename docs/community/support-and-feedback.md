# Support and feedback

This project is self-hosted and community-supported. There is no hosted service promise and no production support SLA.

## Report issues safely
Do include: version/tag, OS, browser, redacted steps, synthetic/disposable/copy status, and sanitized error text.

Do not include: GnuCash books, SQLite DBs, app DBs, backups, CSV exports, screenshots with financial data, `.env`, tokens, keys, certificates, private paths, account names, transaction descriptions, memos, or amounts.

## Deployment boundary
Use trusted LAN/VPN only. The project is not security-audited and is not safe to expose directly to the public internet.

## Write boundary
Public beta is read-only. Controlled writes remain experimental, disabled by default, and not a public write beta.
